# Retail360 Analytics Platform on Snowflake

A retail data analytics project built using SQL and Snowflake.

## Project Overview
Designed and implemented a retail analytics platform by loading 
customer, sales, product and inventory data from CSV files into 
Snowflake and transforming it into meaningful business insights.

## What I Built
- Loaded raw retail data from CSV files into Snowflake
- Designed a 3-layer data architecture (RAW → VALIDATED → CURATED)
  for clean and reliable data processing
- Wrote stored procedures to automate data transformations
- Created SQL queries to generate business KPIs including
  sales performance, customer value and inventory status
- Built Snowflake dashboards to visualize the KPI results
- Applied data masking and role-based access control for security
