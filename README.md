# Retail360 Analytics Platform on Snowflake

A retail data analytics project built using SQL and Snowflake.

## Project Overview
Built an end-to-end retail analytics pipeline by loading CSV data 
into Snowflake and transforming it into business dashboards.

## Data Pipeline Flow
CSV Files → Snowflake Stage → RAW → VALIDATED → CURATED → Dashboards

## What I Built
- Created Snowflake Stage and used COPY INTO to load CSV files
- RAW layer: stored original uncleaned data as-is
- VALIDATED layer: cleaned and transformed the raw data
- CURATED layer: final clean data used for dashboard reporting
- Wrote stored procedures to automate data transformations
- Created SQL queries to generate business KPIs including
  sales performance, customer value and inventory status
- Built Snowflake dashboards to visualize KPI results
- Applied data masking and role-based access control for security
